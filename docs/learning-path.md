# 五节实践课

1. **初始化地图**：阅读 map.ts，分别识别 View、Layer、Source、Feature；关闭在线底图验证离线可用。
2. **理解坐标**：添加一个点并导出 GeoJSON，对照底部坐标与文件中的 WGS84 经纬度。解释为什么显示投影不是经纬度。
3. **操作交互**：绘制线面，切换选择与编辑顶点，观察长度/面积改变。练习增加一个只读测量提示。
4. **建立数据边界**：阅读 geojson.ts，尝试导入非法坐标或未闭合面；原有要素应不受影响。练习为 MultiPoint 增加契约和测试，而不是直接放开所有输入。
5. **验证交付**：运行单元测试、生产构建和浏览器测试。在 360px、768px、1440px 检查操作入口；练习为图层显隐增加状态和验收测试。

验收：无需外网瓦片即可完成标注、编辑、导出、清空、导入的完整流程；导出的数据可以重新导入；失败操作有明确反馈且不破坏当前图层。
